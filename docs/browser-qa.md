# 실제 브라우저 검증 · 2026-09-07

Codex 인앱 브라우저 1280×720, 4203 로컬 서버에서 일반 입력으로 확인했습니다. 상태 주입과 점수 조작은 사용하지 않았습니다.

- 출동하기 → 대원 선택 → 작전 시작, 유리빛 대로 진입과 적 등장.
- 실제 `Z / X / C` 입력 후 공격 효과, 교대, 3 HIT COMBO와 점수 2,240을 확인했습니다.
- 이후 전멸 화면에서 실제 점수 2,240/최고 콤보 3 표시 → 다시 출동으로 홍염 HP 120/점수 0 초기화를 확인했습니다.
- 재시작한 경기에서 `Space / Z` 짧은 탭 후 공중 공격 포즈·피격된 적·2 HIT COMBO·400점을 확인했습니다. `preview.jpg`는 이 실제 플레이 화면입니다.
- `Escape`로 일시정지 대화상자와 계속하기/처음부터 버튼을 확인했습니다.
- 최종 화면은 스프라이트 옆 칸이 섞이지 않으며, 반복 사각형 도시를 전용 유리도시 원화로 교체한 상태입니다. 주요 HUD/전투/조작 안내가 720px 화면 안에 함께 보입니다.
- 검수 콘솔의 경고/오류 기록은 비어 있었습니다.

39개 CPU 테스트의 정상 입력 정책이 9웨이브·보스·합체·협동 결정타·엔딩을 완주한 것과 위 실제 브라우저 짧은 플레이를 구분합니다. 사람이 브라우저에서 3구역을 연속 완주한 결과, 실제 휴대전화 터치, 오디오 청취, 장시간 성능은 미검증입니다. 메카 등 `previews/` 이미지는 CPU 검토 프레임입니다.
